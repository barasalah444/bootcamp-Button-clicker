# bootcamp-Button-clicker


A responsive dictionary web application built using HTML5, CSS3, and JavaScript. This project focuses on implementing clean layouts with Flexbox and interacting with the DOM through events like button clicks.

---

## Features

* **Interactive Navbar:** Includes a functional search input and a context-aware Login/Logout button that dynamically changes text and background colors when clicked.
* **Flexbox Layout:** Organized structural design utilizing a multi-column setup (`left-col` and `right-col`) to separate core word definitions from supplementary interaction zones.
* **Dynamic DOM Interaction:** Integrated JavaScript functions that trigger browser alerts upon clicking the like buttons and completely eliminate elements from the viewport once actions are performed (e.g., removing the "Add Definition" button).
* **Consistent UI Styling:** Customized button components featuring distinct borders, bold weights, shadow highlights, and functional colors.

---

## Project Structure

The repository contains the following files:
* `index.html` - Semantic structure and content markup.
* `style.css` - Custom styling rules, formatting, layout configurations, and responsive structures.
* `main.js` - Client-side interactive logic and functional event handling.
